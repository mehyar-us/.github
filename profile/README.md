# MehyarSoft LLC

Brooklyn software studio. We design, build, and operate AI products end to end — 30+ live products, one studio, everything in-house.

**Flagship — [The Mayor](https://mayor.mehyar.us):** an AI front desk for local businesses. *Mayor. Talk to your business.* It answers missed calls, texts back leads, runs bookings and follow-ups, and builds the week's posting plan — the owner just talks to it.
